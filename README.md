### 🤖 Local Multi-PDF RAG Assistant

An AI-powered assistant that allows users to ask questions from multiple PDF documents using a local RAG pipeline.

**Technologies:** ChromaDB, Sentence-Transformers, Ollama, React, Tailwind CSS, shadcn/ui

**Main Features:**
- PDF ingestion and semantic chunking
- Embeddings generation and persistent vector indexing
- Local LLM integration with Ollama
- Citation-backed Q&A
- Structured summaries and MCQ generation
- Markdown / PDF export
